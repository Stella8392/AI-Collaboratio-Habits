# PPT / 汇报材料制作模板

## 适用场景

领导讲话、项目汇报、讲课材料、工作目标图、业务方案汇报。

## 推荐流程

1. **理解任务和受众**：明确汇报对象、场景、时长、语气、禁改范围。
2. **阅读原文档 / PPT / 备注**：提取已有内容、备注、旧口径、必须保留的信息。
3. **提炼主线**：先做“汇报逻辑大纲”，每页只保留一个核心观点。
4. **先做 HTML / Markdown 草稿**：用可快速审阅的方式确定内容和版式方向。
5. **自审检查**：逻辑是否顺、口径是否统一、是否适合领导讲、是否有错别字。
6. **生成可编辑 PPT**：优先保留原格式；图示尽量用可编辑形状或 SVG，不要只贴死图。
7. **导出预览检查**：检查版式、字号、重叠、旧口径、图片清晰度。
8. **输出修改版 + 修改说明 + 待确认项**。

## 页面模板

```text
【核心观点】一句话说明本页结论。
【简短解读】2-3 句大白话说明为什么重要。
【图示/例子】极简流程图、对比图、指标卡或典型案例。
```

## 禁止事项

- 不要每页堆满文字；
- 不要写研究过程和过多模型推导；
- 不要使用听众难理解的学术化表达；
- 不要未经确认替换核心口径或事实；
- 不要覆盖原文件，除非用户明确要求。

## 输出

```text
1. PPT 修改版文件
2. 每页修改说明
3. 已检查事项
4. 待确认问题
```
