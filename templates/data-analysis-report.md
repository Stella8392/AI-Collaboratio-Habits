# 数据分析报告模板

## 流程

1. 口径确认：指标定义、时间周期、过滤条件、分子分母、异常处理。
2. 数据质量检查：缺失、重复、异常、字段含义不一致。
3. 趋势观察：同比、环比、MTD、近 7/14/30 天等。
4. 结构拆解：城市、门店、SKU、订单、时段、渠道、冷链/非冷链等。
5. 归因判断：识别持续低效、高转低、新增低效、结构变化等。
6. 重点对象：输出优先治理清单。
7. 优化建议：短期监控、中期流程、长期系统机制。
8. 风险提示：数据限制、口径争议、待补充资料。

## 报告结构

```text
1. 结论摘要
2. 口径说明
3. 整体趋势
4. 下降/异常归因
5. 链路瓶颈
6. 重点对象清单
7. 优化建议
8. 待确认项
```
