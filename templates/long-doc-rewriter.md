# 长文档总结与系统性改写模板

## 流程

1. 判断文档类型：政府材料、申报书、案例集、学术报告、白皮书等。
2. 明确目标：降 AI 痕迹、增强材料感、补逻辑、补口径、压缩口号。
3. 提取事实：只使用原文和用户提供资料，不新增未经确认事实。
4. 重构表达：删空泛表述，补业务场景、案例依据、分层判断和推广边界。
5. 检查风格：正式、稳健、克制、准确。
6. 输出修改说明和待确认项。

## 常用结构

```text
背景/问题 → 建设内容 → 技术路径 → 应用场景 → 实施成效 → 经验启示 → 推广边界
```

## 检查清单

- 是否存在口号化表达；
- 是否每个判断都有材料依据；
- 是否把推测写成事实；
- 是否虚构数据或出处；
- 是否案例之间差异明显；
- 是否保留了用户要求的格式和标题。
